# Sentinel Prime Android

Scaffold inicial do aplicativo Android nativo do Sentinel Prime, alinhado ao MVP documentado.

## Escopo atual

- Splash screen inicial
- Fluxo visual de login e cadastro
- Dashboard com resumo financeiro
- Navegação local entre telas principais do MVP
- Base pronta para integrar com a API Spring Boot futuramente

## Stack

- Java
- Android Views com XML
- Material Components

## Próximos passos

- Adicionar Gradle Wrapper pelo Android Studio ou `gradle wrapper`
- Configurar consumo da API
- Implementar autenticação real
- Persistir sessão
- Integrar dashboard, transações e categorias com o backend
